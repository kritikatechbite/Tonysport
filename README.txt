Maple Sports Hub - static website (HTML5, CSS3, vanilla JavaScript)

1. Upload the contents of this folder to any static host (cPanel, Hostinger, Netlify, GitHub Pages).
2. Set your real domain in canonical, Open Graph, sitemap and robots files:
     ./set-domain.sh https://www.yourdomain.ca
   (Until then they contain the placeholder https://YOUR-DOMAIN.TLD.)
3. Add a real contact email in about.html (#contact) and in the contact section of each policy page.
4. Replace the generated illustrations in assets/images with licensed photography if you want
   photographic imagery (keep the same file names and aspect ratios).
5. Event fixtures and articles are labelled demonstration/sample content. Replace with verified
   information before presenting them as real.
6. If you add analytics, cookies or other third-party services, update the Privacy and Cookie policies.
